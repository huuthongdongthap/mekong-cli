1. TỔNG QUAN

Mekong CLI là nền tảng AI tự động hóa doanh nghiệp, biến mục tiêu ngôn ngữ tự nhiên thành hành động thực thi qua pipeline Plan → Execute → Verify (PEV).

Thống kê: 289 commands • 245 skills • 176 contracts • 13 agents • 9 sub-apps

Cách hoạt động

"Tạo FastAPI service với JWT auth"
  ↓ PLAN → Phân tách thành các bước (LLM-powered)
  ↓ EXECUTE → Thực thi từng bước (shell/llm/tool/browse/evolve)
  ↓ VERIFY → Kiểm tra kết quả theo quality gates
  ↓ DONE → Hoàn thành, MCU credits trừ

6. PEV ENGINE (Core)

6.1 Orchestrator (1023 lines)

RecipeOrchestrator
├── StepExecutor      — Thực thi + verify từng bước
├── RollbackHandler   — Rollback khi thất bại
└── ReportFormatter   — Rich terminal reporting

6.2 Planner (660 lines)

  • Phân tách goal thành atomic tasks qua LLM
  • DAG-aware planning (parallel khi có thể)
  • Re-planning tự động khi branch thất bại
  • Agent keyword routing (git/file/shell/lead/content/browse/evolve)

6.3 Executor (490 lines) — 5 chế độ

Mode Mô tả
shell subprocess.run với retry + sanitization
llm LLM generation qua provider
api HTTP request (GET/POST/PUT/DELETE)
tool ToolRegistry execution
browse BrowserAgent (web extraction)

6.4 Verifier (483 lines)

  • Exit code check
  • File exists/not exists
  • Output contains/not contains
  • Custom check (shell command)
  • Binh Pháp Quality Gates: 0 TODO, 0 console.log, 0 :any, 0 vulnerabilities

6.5 Self-Healing Flow

Step fails → Reflection Engine phân tích root cause
  ↓ World Model kiểm tra environment
  ↓ LLM tạo correction strategy
  ↓ Retry với exponential backoff (max 3 retries)
  ↓ Nếu vẫn fail → Rollback + Dead Letter Queue

12. SWARM REGISTRY (Multi-Node)

Phân phối task across multiple Mekong gateways:

# Register node
registry.register_node(name, host, port, token)

# Health check all nodes
registry.check_all_health()

# Dispatch goal to specific node
registry.dispatch_goal(node_id, goal)

Priority: Healthy remote node → Local agent fallback
